# LSTM으로 S&P 500 다음 날 종가 예측

## 1. 문제 정의

kospi보다 변동성이 적은 S&P 500의 지난 60거래일 데이터를 보고 다음 거래일 종가를 예측한다. 종가만 쓰지 않고 가격과 여러 기술적 지표를 같이 넣었다.

## 2. 데이터 설명

`yfinance`로 Yahoo Finance의 S&P 500 지수(`^GSPC`) 데이터를 가져왔다. 2000년 1월부터 가져왔으며 노트북에 저장된 데이터의 마지막 날짜는 2026년 10월 5일

사용한 입력은 총 11개

| Feature | 뜻 |
|---|---|
| `Open`, `High`, `Low`, `Close` | 시가, 고가, 저가, 종가 |
| `SMA_20` | 20거래일 이동평균선 |
| `RSI_14` | 14거래일 RSI |
| `BB_upper`, `BB_lower` | 볼린저 밴드 위·아래 선 |
| `MACD`, `MACD_signal` | MACD와 신호선 |
| `Williams_R` | 14거래일 Williams %R |

지표는 Yahoo Finance에서 가져온 가격으로 `ta` 라이브러리를 사용해 만들었음

## 3. 전처리 과정

- 날짜순으로 정렬
- 지표를 계산하면서 처음에 생긴 결측값은 `dropna()`로 제거
- 2026년 8월까지 학습, 9월 검증, 10월 테스트로 나눴다.
- `StandardScaler`로 입력과 정답인 종가를 각각 표준화
- 스케일러는 학습 데이터에만 맞춤
- 직전 60거래일을 입력 하나로 묶고, 다음 거래일 종가를 정답으로 만들었다.

시퀀스는 학습 6,612개, 검증 21개, 테스트 3개가 만들어졌다.

## 4. LSTM 입력 구조

입력 모양은 `(batch_size, sequence_length, input_size)`다.

- `batch_size = 64`: 한 번에 학습하는 데이터 64개
- `sequence_length = 60`: 직전 60거래일
- `input_size = 11`: 하루에 넣는 가격과 지표 11개

실제 학습 배치의 모양은 `(64, 60, 11)`이다.

## 5. 모델 구조

PyTorch의 LSTM을 사용했다.

- `input_size = 11`
- `hidden_size = 64`
- `num_layers = 2`
- `dropout = 0.2`
- `batch_first = True`

LSTM의 마지막 시점 출력을 선형층에 넣어 종가 하나를 예측했다. Colab에서는 GPU를 사용했다.

## 6. 학습 방법

- Loss: `MSELoss`
- Optimizer: `AdamW`
- Learning rate: `1e-3`
- Weight decay: `1e-4`
- 최대 Epoch: 50
- Early Stopping: 검증 손실이 8 epoch 동안 좋아지지 않으면 중단
- Gradient clipping: 최대 norm `1.0`

검증 손실이 가장 낮았던 모델을 저장해서 평가에 사용했다. 실제 학습은 29 epoch에서 멈췄다.

## 7. 결과 및 평가

10월 데이터 3거래일을 테스트했다. RMSE와 MAE는 낮을수록 좋으며 `Persistence`는 다음 날 종가를 전날 종가와 같다고 예측한 결과다.

| 모델 | RMSE | MAE |
|---|---:|---:|
| Persistence | 40.4962 | 36.7703 |
| LSTM | 52.5235 | 44.4198 |

종가를 예측하는 회귀 문제라 Accuracy는 사용하지 않았다.

## 8. 결과 분석

1차 실험 다음 실험에는 상단 내용이 변경될 수 있음. 
먼저 여러 번 테스한 결과 지금의 결과가 가장 좋았으며 Loss 그래프를 확인하면 val loss는 처음부터 낮게 시작이 되었다. 그리고 17 epoch에 0.01에서 0.04에 근접하게 튀는 모습을 관찰할 수 있었다. 예측 결과는 주가 하락한다고 예측을 하지 않았으며 우상승하는 모습을 볼 수 있다. 결과적으로만 보면 상승이라 예측은 맞는 것 같아 보여도 실질적으로 10월 05일 기준(장 열림)으로 약 7760이지만 예측은 약 7690인 모습을 볼 수 있다. 
그래서 추가적으로 해야 할 실험은
1. val과 test를 더 늘리기
2. 더 많은 지표를 가져와 적용
3. 차트가 불안정한 종목 가져와 학습
4. 한국 시장의 대기업들을 적용
5. 여러 하이퍼파라미터 수정
<br>등 성능은 더 발전 시킬 가능성은 남아있다.
